# Доброта

Приложение для добрых дел: отмечай хорошие поступки, получай баллы и поднимайся в рейтинге.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

Локально используется тестовый участник и in-memory база (PGlite). После публикации в Cursor (private или team) данные хранятся в Postgres, а имя берётся из аккаунта Cursor.
